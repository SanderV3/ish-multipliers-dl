# TransAxx pip requirements (GPU)
# Paper explicitly states: "TransAxx was built on PyTorch 1.13 with
# CUDA Version 11.7." We use the matching cu117 wheels.
#
# PINNED for the frozen paper artifact (Ten Simple Rules, rule 5: specify
# software versions), the same convention as requirements-analysis.txt. Captured
# from the rp-transaxx image that produced the committed results, on 2026-07-25:
#
#   docker run --rm --entrypoint python3 rp-transaxx -m pip freeze
#
# Direct dependencies first, then their transitive closure. To bump a version,
# edit a direct dep, rebuild rp-transaxx, and re-freeze into this file.
#
# NOT listed here: pytorch-quantization. It is NOT the pypi package -- the
# Dockerfile installs the vendored fork at transaxx/pytorch-quantization/ as an
# editable install after the clone, because TransAxx's layers depend on that
# exact fork. Its own deps (absl-py, prettytable, sphinx_glpi_theme) are pinned
# below since they end up in the final environment.

--extra-index-url https://download.pytorch.org/whl/cu117
--extra-index-url https://pypi.ngc.nvidia.com

# --- direct ---
torch==1.13.1+cu117
torchvision==0.14.1+cu117

# Build tooling pins. PyTorch 1.13's cpp_extension.py does
# `from pkg_resources import packaging`, which setuptools 70+ removed.
# Pin under 70 to keep PyTorch's JIT extension builds working. Left as a
# range, not ==, because ubuntu 22.04 already ships 59.6.0 via apt and that
# satisfies it, so pip leaves the system copy alone.
setuptools<70
wheel

# Vision Transformer models -- TransAxx evaluates on ViT, DeiT, Swin,
# GCViT. timm is the de-facto source for pretrained ViT variants, and it
# supplies both the architecture and the weights. A bare model name resolves
# to a default pretrained tag that belongs to the timm version
# (vit_base_patch16_224 -> augreg2_in21k_ft_in1k, pulled from the HuggingFace
# hub), so an unpinned timm can swap the weights under a re-run and move the
# numbers with nothing in runs.csv to show for it.
timm==1.0.27
