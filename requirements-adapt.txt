# AdaPT pip requirements (CPU-only)
# AdaPT's provided docker is around PyTorch 1.10-1.11. We use 1.13 CPU
# wheel since it's the last 1.x CPU wheel still easily installable and
# matches what TransAxx uses, keeping the codebases closer in behavior.
# If you want to mirror the AdaPT docker exactly, drop to 1.11.
#
# PINNED for the frozen paper artifact (Ten Simple Rules, rule 5: specify
# software versions), the same convention as requirements-analysis.txt. Captured
# from the rp-adapt image that produced the committed results, on 2026-07-25:
#
#   docker run --rm --entrypoint python3 rp-adapt -m pip freeze
#
# Direct dependencies first, then their transitive closure. To bump a version,
# edit a direct dep, rebuild rp-adapt, and re-freeze into this file.
